# 📊 Blinkit Sales & Delivery Analytics (Power BI)

Interactive Power BI dashboard analyzing Blinkit sales and delivery performance across **8,500+ records** — built to surface revenue trends, order performance, delivery efficiency, and category-level sales for business decision-making.

## 🎯 Objectives

- Monitor overall sales performance and growth trends
- Identify top-performing categories and products
- Track order volume, revenue, and delivery KPIs
- Enable quick decision-making through interactive visuals and filters

---

## 🗂 Dataset

| | |
|---|---|
| **Records** | 8,500+ |
| **Type** | Sales + delivery transactions |
| **Tool** | Power BI (Power Query for cleaning, DAX for measures) |

---

## 📌 Key KPIs Tracked

- Total Revenue
- Total Orders
- Average Order Value (AOV)
- Delivery Performance (time / status)
- Top Categories by Sales
- Month-wise and category-wise trends

---

## 📈 Dashboard Features

- KPI cards for quick performance view
- Slicers for interactive filtering (Category, Month, City, etc.)
- 10+ visuals: bar charts, line charts, donut charts, tables
- Drill-down insights for deeper business analysis

## 🚀 How to Use

1. Download `power_bi/Blinkit_Sales_Delivery_Analytics.pbix` from this repository
2. Open it in **Power BI Desktop**
3. Refresh data if needed (Home → Refresh) — source path points to `data/blinkit_grocery_data.xlsx`
4. Use slicers and filters to explore insights
